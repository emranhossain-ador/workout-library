# 🏋️ FitLog — Workout & Fitness Tracker

> **Train with intent. Log every set.**

FitLog is a modern workout and fitness tracking web application built with Next.js.  
It helps users explore workouts, view detailed exercise information, create a daily workout plan, save favorite exercises, and track workout progress.

---


## ✨ Features

### 🏋️ 1. Workout Library
- Browse a collection of workouts.
- View exercise image, name, muscle groups, equipment, duration, calories, and rating.
- Responsive workout grid for all screen sizes.

### 📋 2. My Workout Plan
- Add exercises to today's workout plan.
- View all selected exercises in one place.
- Track total exercises, workout time, and calories.

### ❤️ 3. Save Workouts
- Save exercises for later.
- Easily access saved workouts from the My Plan page.
- Remove saved exercises whenever needed.

### 🔍 4. Workout Details
- View complete exercise information.
- Includes description, instructions, difficulty, equipment, sets, reps, and more.
- Add the exercise directly to today's plan or save it for later.

### 📊 5. Sorting & Organization
- Sort workouts by:
  - Duration
  - Calories
  - Rating
- Quickly organize exercises based on your preference.

### 💾 6. Local Storage Persistence
- Workout plans are saved in browser local storage.
- Selected workouts remain available even after refreshing the page.

### 📱 7. Fully Responsive Design
- Optimized for:
  - 📱 Mobile
  - 📲 Tablet
  - 💻 Desktop
- Clean and modern dark fitness-focused UI.

### 🔔 8. Toast Notifications
- Shows feedback when adding, saving, removing, or completing workouts.
- Provides a better user experience.
